## ☁️ AWS Deployment Guide (Step-by-Step)

### 📋 What You Need Before Starting
- [ ] AWS Account (free tier is fine to start)
- [ ] MongoDB Atlas already set up ✅ (you already have this)
- [ ] Domain name (optional but recommended, ~₹1000/year from GoDaddy or Namecheap)

---

### 🚀 STEP 1: Launch an AWS EC2 Instance

1. Go to [AWS Console](https://console.aws.amazon.com/) → **EC2** → **Launch Instance**
2. **Settings:**
   - **Name:** `hrms-server` or `espresso-server`
   - **AMI:** Ubuntu Server 22.04 LTS (Free Tier eligible)
   - **Instance Type:** `t2.micro` (free tier) or `t3.small` ($15/mo) for production
   - **Key Pair:** Create a new key pair → Download `your-key.pem` → **SAVE THIS FILE**
   - **Security Group (Firewall rules):** Add these inbound rules:
     | Type | Port | Source |
     |------|------|--------|
     | SSH | 22 | My IP |
     | HTTP | 80 | 0.0.0.0/0 |
     | HTTPS | 443 | 0.0.0.0/0 |
     | Custom TCP | 3000 | 0.0.0.0/0 | ← (HRMS)
     | Custom TCP | 2000 | 0.0.0.0/0 | ← (Espresso)
3. Click **Launch Instance**
4. Note the **Public IPv4 address** (e.g., `13.233.xx.xx`)

---

### 🔌 STEP 2: Connect to Your EC2 via SSH

On your Mac terminal:

### 🌐 STEP 7: Set Up Nginx (Port 80 → Your App)

So people can access via `http://your-domain.com` instead of `:3000`:

```bash
# Install Nginx
sudo apt install nginx -y

# Create config for HRMS
sudo nano /etc/nginx/sites-available/hrms
```

Paste:
```nginx
server {
    listen 80;
    server_name YOUR_EC2_IP_OR_DOMAIN;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

```bash
# Enable and reload
sudo ln -s /etc/nginx/sites-available/hrms /etc/nginx/sites-enabled/
sudo nginx -t           # Test config
sudo systemctl reload nginx
```

Now visit: `http://YOUR_EC2_IP` → should show your HRMS!

## 🗺️ MongoDB Atlas: Allow EC2 IP Access

> [!CAUTION]
> This is a critical step — your app will fail to connect to DB without this!

1. Go to [MongoDB Atlas](https://cloud.mongodb.com/)
2. Click your cluster → **Network Access** (left sidebar)
3. Click **+ Add IP Address**
4. Enter your EC2 Public IP (e.g., `13.233.xx.xx/32`)
5. Or click **Allow Access from Anywhere** (0.0.0.0/0) for testing
6. Click **Confirm**
